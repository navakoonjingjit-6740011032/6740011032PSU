โจทย์ 1 : โจทย์

สร้างหน้าโปรไฟล์ส่วนตัวอย่างง่ายด้วย HTML คุณได้รับมอบหมายให้สร้างหน้าเว็บ HTML อย่างง่ายเพื่อแสดงข้อมูลโปรไฟล์ส่วนตัวของคุณ ซึ่งจะประกอบด้วยชื่อ รูปภาพ และข้อมูลพื้นฐานอื่นๆ ที่สำคัญ โจทย์นี้จะช่วยให้คุณคุ้นเคยกับการใช้งานแท็ก HTML พื้นฐานในการจัดโครงสร้างเนื้อหาบนหน้าเว็บ

สิ่งที่โจทย์ต้องการ:

  • สร้างหัวข้อหลักสำหรับชื่อของคุณโดยใช้แท็ก <h1>
  • เพิ่มรูปภาพโปรไฟล์ของคุณโดยใช้แท็ก <img> (สามารถใช้รูป placeholder ได้)
  • สร้างย่อหน้า <p> อธิบายเกี่ยวกับตัวคุณสั้นๆ
  • สร้างรายการข้อมูลติดต่อโดยใช้ <ul> และ <li>
  • ใช้แท็ก <a> เพื่อสร้างลิงก์ที่ใช้งานได้จริง

โจทย์ 2 : โค้ด

<!DOCTYPE html>
<html lang="th">
  <head>
    <meta charset="UTF-8" />
    <title>โปรไฟล์ส่วนตัว</title>

    <style>
      body {
        font-family: Arial, sans-serif;
        background-color: #f4f6f8;
        text-align: center;
        padding: 40px;
      }

      h1 {
        color: #333;
        margin-bottom: 20px;
      }

      img {
        width: 150px;
        height: 150px;
        border: 3px solid #ddd;
        margin-bottom: 20px;
      }

      p {
        color: #555;
        max-width: 500px;
        margin: 0 auto 30px;
        line-height: 1.6;
      }

      h2 {
        color: #333;
        margin-bottom: 10px;
      }

      ul {
        list-style: none;
        padding: 0;
      }

      li {
        margin: 8px 0;
      }

      a {
        text-decoration: none;
        color: #0066cc;
        font-weight: bold;
      }

      a:hover {
        color: #003366;
      }
    </style>
  </head>
  <body>
    <h1>John Doe</h1>

    <img src="https://via.placeholder.com/150" alt="Profile Picture" />

    <p>
      ผมเป็นผู้ที่สนใจด้านการพัฒนาเว็บไซต์ ชอบเรียนรู้เทคโนโลยีใหม่ ๆ
      และสนุกกับการเขียนโค้ดในเวลาว่าง
    </p>

    <h2>Contact Information</h2>
    <ul>
      <li><a href="mailto:john.doe@example.com">Email</a></li>
      <li><a href="https://www.linkedin.com" target="_blank">LinkedIn</a></li>
      <li><a href="https://github.com" target="_blank">GitHub</a></li>
    </ul>
  </body>
</html>
