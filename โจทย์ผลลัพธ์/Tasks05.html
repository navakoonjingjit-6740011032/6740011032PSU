โจทย์ 1 : โจทย์

สร้างแบบฟอร์มลงทะเบียนกิจกรรมออนไลน์ ผู้ใช้จะต้องสร้างหน้า HTML สำหรับแบบฟอร์มลงทะเบียนเข้าร่วมกิจกรรมออนไลน์ โดยใช้แท็ก HTML ที่หลากหลายเพื่อให้ได้โครงสร้างที่เหมาะสมและมีฟังก์ชันการทำงานเบื้องต้น

สิ่งที่โจทย์ต้องการ:

  • ใช้แท็ก <form> สำหรับสร้างแบบฟอร์ม
  • มีช่องชื่อ-นามสกุล ใช้ <input type="text"> และ <label>
  • มีช่องอีเมล ใช้ <input type="email"> และ <label>
  • มีตัวเลือกเพศ ใช้ <input type="radio"> พร้อม <fieldset> และ <legend>
  • มีตัวเลือกประเภทกิจกรรม ใช้ <select> และ <option> อย่างน้อย 3 ตัวเลือก
  • มีช่องข้อความเพิ่มเติม ใช้ <textarea>
  • มีปุ่มส่งข้อมูล ใช้ <button type="submit">
  • ใช้ Semantic HTML5 เช่น <header>, <main>, <footer>
  • ทุกช่องต้องมี label เชื่อมกับ id และ for
  • กำหนด required ให้ช่องชื่อ-นามสกุลและอีเมล

โจทย์ 2 : โค้ด

<!DOCTYPE html>
<html lang="th">
  <head>
    <meta charset="UTF-8" />
    <title>แบบฟอร์มลงทะเบียนกิจกรรม</title>
  </head>
  <body>
    <header>
      <h1>แบบฟอร์มลงทะเบียนกิจกรรม</h1>
    </header>

    <main>
      <form action="#" method="post">
        <div>
          <label for="fullname">ชื่อ-นามสกุล:</label>
          <input type="text" id="fullname" name="fullname" required />
        </div>

        <div>
          <label for="email">อีเมล:</label>
          <input type="email" id="email" name="email" required />
        </div>

        <fieldset>
          <legend>เพศ</legend>

          <input type="radio" id="male" name="gender" value="male" />
          <label for="male">ชาย</label>

          <input type="radio" id="female" name="gender" value="female" />
          <label for="female">หญิง</label>
        </fieldset>

        <div>
          <label for="activity">ประเภทกิจกรรมที่สนใจ:</label>
          <select id="activity" name="activity">
            <option value="sports">กีฬา</option>
            <option value="music">ดนตรี</option>
            <option value="technology">เทคโนโลยี</option>
          </select>
        </div>

        <div>
          <label for="message">ข้อความเพิ่มเติม / คำถาม:</label>
          <textarea id="message" name="message" rows="4" cols="30"></textarea>
        </div>

        <div>
          <button type="submit">ส่งข้อมูล</button>
        </div>
      </form>
    </main>

    <footer>
      <p>© 2026 ตัวอย่างเว็บไซต์</p>
    </footer>
  </body>
</html>
