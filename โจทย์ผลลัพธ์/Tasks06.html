โจทย์ 1 : โจทย์

สร้างฟอร์มการสมัครสมาชิกเชิงลึกพร้อมโครงสร้างข้อมูลเชิงความหมาย คุณได้รับมอบหมายให้สร้างฟอร์มการสมัครสมาชิกที่มีความซับซ้อนสำหรับเว็บไซต์ E-commerce โดยต้องเน้นการใช้ HTML5 อย่างถูกต้องตามหลักความหมาย เพิ่มความสามารถในการเข้าถึง (Accessibility) ด้วย ARIA attributes และผสานรวม Microdata เพื่อปรับปรุง SEO

สิ่งที่โจทย์ต้องการ:

  • ใช้ Semantic HTML5 เช่น <form>, <fieldset>, <legend>, <label>
  • จัดกลุ่มข้อมูลอย่างน้อย 3 ส่วน (ข้อมูลส่วนตัว, ที่อยู่, การชำระเงิน)
  • เพิ่ม ARIA attributes เช่น aria-labelledby, aria-describedby, aria-required, role
  • ผสาน Microdata (Schema.org) สำหรับข้อมูลผู้ใช้
  • ใช้ input types ที่เหมาะสม เช่น email, tel, date, number, password
  • ใช้ client-side validation เช่น required, pattern, minlength, maxlength

โจทย์ 2 : โค้ด

<!DOCTYPE html>
<html lang="th">
  <head>
    <meta charset="UTF-8" />
    <title>แบบฟอร์มลงทะเบียนผู้ใช้</title>
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  </head>

  <body>
    <main>
      <h1 id="form-title">แบบฟอร์มลงทะเบียน</h1>

      <form aria-labelledby="form-title">
        <fieldset itemscope itemtype="https://schema.org/Person">
          <legend>ข้อมูลส่วนตัว</legend>

          <label for="fullname">ชื่อ-นามสกุล</label>
          <input type="text" id="fullname" required minlength="3"
            aria-required="true" itemprop="name" />

          <label for="email">อีเมล</label>
          <input type="email" id="email" required
            aria-required="true" itemprop="email" />
        </fieldset>

        <fieldset itemscope itemtype="https://schema.org/PostalAddress">
          <legend>ที่อยู่</legend>
          <textarea id="address" required itemprop="streetAddress"></textarea>
        </fieldset>

        <fieldset>
          <legend>ข้อมูลการชำระเงิน</legend>
          <input type="password" pattern="[0-9]{16}" required />
        </fieldset>

        <button type="submit">ส่งข้อมูล</button>
      </form>
    </main>
  </body>
</html>
